# DIGINTECH Technologies (Pvt) Ltd — Website

A responsive React + Vite company website using a premium dark navy, electric blue and cyan visual style.

## Included
- Responsive navigation and mobile menu
- Hero section with custom CSS digital illustration
- Seven service cards
- About section and working approach
- Contact form that opens WhatsApp with the enquiry prefilled
- Click-to-call phone link
- Responsive footer
- SEO title and description metadata
- Reduced-motion support and accessible form labels

## Requirements
- Node.js 18+ (Node.js 20 LTS recommended)
- npm

## Run locally
```bash
npm install
npm run dev
```
Vite prints a local URL, usually `http://localhost:5173`.

## Production build
```bash
npm run build
npm run preview
```
The production website is generated in `dist/`.

## Deploy
The `dist/` folder can be deployed to static hosting such as Azure Static Web Apps, Netlify, Vercel, or another static web host.

## Contact form
The PROJECT ENQUIRY form requires name, email, phone number, service and project message. It opens WhatsApp at `+94 77 860 8207` with all enquiry details prefilled. The visitor reviews and sends the message; WhatsApp does not send automatically. No backend is required for this flow.

## Before publishing
- Confirm the registered company name and domain.
- Replace or confirm any future contact details when available.
- Test the WhatsApp link and the layout on mobile.
- If a server-side form is preferred, connect a secure backend or form provider; do not put private API keys in frontend code.
